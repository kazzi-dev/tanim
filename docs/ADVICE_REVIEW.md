# Tanim advice: review sheet

Tanim is a phone app that guesses which rice leaf disease is in a photo. After the guess it shows the
text below. **Please check it before farmers rely on it.** Mark each line OK, or write what it should say.
The app always adds: *"Tanim is a study project, not a diagnosis. Before spraying or pulling plants,
check with your Municipal Agriculture Office."*

Reviewer: ______________________ Office: ______________________ Date: __________

## Bacterial leaf blight

| | Text in the app | OK? | Correction |
|---|---|---|---|
| Cause | Bacteria (Xanthomonas oryzae pv. oryzae) | ☐ | |
| What it looks like | Yellow to straw-coloured streaks that start at the leaf tip or edges and spread down, often with wavy margins. | ☐ | |
| Step 1 | There is no spray that cures it, so save your money on fungicides. | ☐ | |
| Step 2 | Go easy on nitrogen (urea) and use balanced fertilizer; heavy nitrogen makes it worse. | ☐ | |
| Step 3 | Drain the field for a few days where you can, and avoid moving water from sick plots to healthy ones. | ☐ | |
| Step 4 | Plough under or remove infected stubble and weeds after harvest. | ☐ | |
| Step 5 | Next season, ask for a resistant variety. | ☐ | |

## Rice blast

| | Text in the app | OK? | Correction |
|---|---|---|---|
| Cause | Fungus (Magnaporthe oryzae) | ☐ | |
| What it looks like | Diamond or spindle-shaped spots with grey or whitish centres and brown borders. | ☐ | |
| Step 1 | Split nitrogen into smaller doses instead of one heavy application. | ☐ | |
| Step 2 | Keep the field flooded if you can; dry, stressed rice is hit harder. | ☐ | |
| Step 3 | Ask your agriculturist whether a fungicide is worth it at this stage, and which one. | ☐ | |
| Step 4 | Next season, use clean seed of a resistant variety. | ☐ | |

## Brown spot

| | Text in the app | OK? | Correction |
|---|---|---|---|
| Cause | Fungus (Bipolaris oryzae) | ☐ | |
| What it looks like | Small round to oval brown spots, often with a yellow halo and a grey centre. | ☐ | |
| Step 1 | Brown spot usually means the soil is short on nutrients. Ask for a soil test. | ☐ | |
| Step 2 | Apply balanced fertilizer, especially potassium. | ☐ | |

## Tungro

| | Text in the app | OK? | Correction |
|---|---|---|---|
| Cause | Virus, spread by green leafhoppers | ☐ | |
| What it looks like | Leaves turn yellow to orange from the tip down; plants are stunted with fewer tillers. | ☐ | |
| Step 1 | There is no cure. Pull out and bury infected plants early so leafhoppers can’t spread it. | ☐ | |
| Step 2 | Tell your Municipal Agriculture Office: tungro spreads between farms. | ☐ | |
| Step 3 | Plant at the same time as your neighbours next season, and use a tungro-resistant variety. | ☐ | |
